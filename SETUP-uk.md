# Запуск сайту безкоштовно (Cloudflare) — крок за кроком

Усе нижче безкоштовне й **не потребує банківської картки**. Сайт, база заявок, відгуки й фото живуть у Cloudflare.
Нічого не «засинає» (на відміну від Supabase). Єдине, що може коштувати грошей, — власний домен (`.com.ua` тощо),
але він **необов'язковий**: безкоштовна адреса виду `lime-camp.pages.dev` працює завжди.

## Що потрібно
- Акаунт на cloudflare.com (реєстрація без картки)
- Node.js 20 або новіший (nodejs.org)
- Ця папка (`lime`) на твоєму комп'ютері. Команди виконуй у терміналі, відкритому **всередині цієї папки**.

## 1. Вхід у Cloudflare
```
npx wrangler login
```
Відкриється браузер, натисни «Allow».

## 2. Створи базу й сховище для фото
```
npx wrangler d1 create lime-db
npx wrangler kv namespace create PHOTOS
```
Кожна команда виведе `id`. Відкрий файл `wrangler.toml` і встав їх замість
`ВСТАВ_ID_БАЗИ` (database_id) та `ВСТАВ_ID_KV` (id).

## 3. Створи таблиці
```
npx wrangler d1 execute lime-db --remote --file=schema.sql
```
Таблицю для прайсу (`settings`) адмінка створює сама, окремо нічого запускати не треба.

## 4. Створи проєкт сайту й задай секрети
```
npx wrangler pages project create lime-camp --production-branch=main
npx wrangler pages secret put ADMIN_PASSWORD --project-name=lime-camp
npx wrangler pages secret put SESSION_SECRET --project-name=lime-camp
```
- `ADMIN_PASSWORD` — пароль для адмінки. Придумай довгий (15+ символів), збережи в менеджері паролів.
- `SESSION_SECRET` — довгий випадковий рядок. Отримати його можна командою:
  `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`
  (скопіюй результат і встав, коли команда попросить значення).

## 5. Опублікуй
```
npx wrangler pages deploy
```
У відповіді буде адреса `https://lime-camp.pages.dev` (або схожа). Це і є твій сайт.
Адмінка: `https://твоя-адреса/admin`.

## 6. Оновлювати сайт
Змінила файли в папці `public`? Просто знову виконай `npx wrangler pages deploy`.
Заявки, відгуки й фото з адмінки лежать в базі й **не зникають** при оновленні.

## Прайс і тематики
- **Прайс 2027** уже вшитий у сайт (дві вкладки: «Стандарт» та «Energy dance»). Файл `public/prices-default.json` — це стандартний варіант.
- Змінювати ціни, дати, тематики, колонки, тексти й посилання на форму бронювання найпростіше в адмінці, вкладка **«Прайс»**: натискаєш «Зберегти прайс», і за хвилину зміни на сайті. Повторно `deploy` для цього **не потрібен**.
- Кнопка «Скинути до стандартного» повертає прайс із `prices-default.json`.
- Якщо правиш `prices-default.json` вручну, запусти `node tools/build-prices.js`, а потім `npx wrangler pages deploy`.
- Нова тематика **Lime Jungle** (маскот, три команди) додана в герої, у блоці «Оберіть формат зміни» й окремою секцією «Три команди Lime Jungle».

## Домен lime.camp
Домен підключено через Cloudflare Pages: Workers & Pages → lime-camp → Custom domains (`lime.camp` і `www.lime.camp`). Nameservers домену вказують на Cloudflare.

## Як користуватись адмінкою
- **Прайс:** редактор зі змінами, типами цін, колонками й живим переглядом.
- **Заявки на 2027:** хто залишив контакт (Telegram чи телефон лінком), лічильник нових, «опрацьована», завантаження CSV.
- **Відгуки:** нові від відвідувачів чекають твого схвалення; можна додати свій, сховати чи видалити.
- **Фото:** обираєш рік і зміну, завантажуєш; фото з'являються на сторінках «Фото змін». Якщо додаси фото III зміни, на сторінці з'явиться окрема вкладка.

## Безкоштовні ліміти Cloudflare (на момент перевірки, жовтень 2026)
- Звичайні сторінки й картинки сайту: без обмежень.
- Робота бекенду (форми, адмінка, фото, додані через адмінку): 100 000 запитів на день. Для табору цього з великим запасом.
- Один перегляд фото з адмінки = 1 запит; сторінка з 40 такими фото = 40 запитів.
- База заявок: до 5 ГБ. Сховище фото: 1 ГБ (це кілька тисяч фото; адмінка стискає їх до ~200 КБ).
- Якщо ліміт раптом вичерпається, сервіс просто призупиниться до наступної доби. Платити не доведеться: картки в акаунті немає, тож і списувати нема з чого.
Актуальні цифри: developers.cloudflare.com (розділ Workers → Limits).

## Безпека (коротко)
- Заявки бачиш лише ти (вхід за паролем, 8 невдалих спроб = блок на 15 хвилин).
- Відвідувачі можуть тільки додавати заявки й відгуки (не частіше кількох на годину з однієї адреси).
- Відгуки не публікуються без твого схвалення.
- Заявки містять контакти батьків, тому не передавай нікому пароль, а після набору видаляй непотрібні заявки.
- Фото з iPhone у форматі HEIC Chrome не відкриє: експортуй у JPG.
- Фото, що вже були на сайті, лежать у `public/images` і видаляються вручну з папки (потім повторний `deploy`).
